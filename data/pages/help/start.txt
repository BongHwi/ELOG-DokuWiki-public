====== Help ======

This page explains the basics of using the E-Log: how to read and navigate entries, search for past logs, create new entries, manage attachments, and format content.

===== Quick Start =====

  * Select a **Logbook** from the **Logbooks** row.
  * Open an **Entry** to read.
  * If you have write access, use **New Log** to create an entry.
  * Use **Reply** for a follow-up or a correction.
  * Use **Add Attachment** to add files to an entry that already exists.
  * Use **Find** to search, and **Photos** to browse attachments.

===== Accounts and Access =====

  * **Reading.** Public logbooks can be read without an account. Some logbooks are visible only to their members.
  * **Getting an account.** Click **Login**, then **Register**. After you register, an administrator must approve the account. Until then you can log in, but you cannot write.
  * **Writing.** Approved members can create entries, write replies, and add attachments in the logbooks they have access to.
  * **No editing after saving.** This is a logbook: an entry cannot be changed or deleted after it is saved. Only an administrator can do that. If something is wrong, write a **Reply** with the correction, or ask an administrator.

===== Reading & Navigation =====

  * **Home** takes you to the E-Log front page.
  * Use the **Logbooks** row to switch between logbooks.
  * Open entries by clicking their title in the logbook page.
  * **Index** is available to admins and shows a page index for the current namespace.

Tip: If you want to share a specific place in a page, you can link to a section header using a hash, for example:

  * [[help:start#creating_a_new_entry|Jump to "Creating a New Entry"]]

===== Finding Entries (Find) =====

From a logbook root page, click **Find** to search for entries.

What works well:

  * Search by a unique keyword (run number, detector name, subsystem, error code).
  * Use short phrases rather than full sentences.

If you do not see **Find**, see [[#getting_access_and_troubleshooting|Getting Access and Troubleshooting]] below.

===== Creating a New Entry =====

To create an entry:

  * Go to the logbook root page
  * Click **New Log**
  * Fill in your content and save

Read the entry once more before you save it. You cannot edit it later. To correct a mistake, open the entry and click **Reply**.

If the form was open for a long time, your login can expire. Copy your text before you save, so that you can paste it again after you log in.

Suggested entry template:

  * **Title:** short and specific
  * **Summary:** 1-3 sentences (what happened, impact)
  * **Details:** data, steps taken, screenshots, links
  * **Next actions:** who/what/when

===== Photos & Attachments =====

  * **While writing:** drag images into the upload area of the form, or click it to select files.
  * **Later:** open the entry and click **Add Attachment**. This adds files only. The text of the entry does not change.
  * **File types:** images and ROOT files (''.root''). Other file types are refused.
  * Attachments can be removed only by an administrator.

Use **Photos** to browse media files attached to entries.

You can also embed an uploaded image inside an entry. Common examples:

  * Embed an internal image: {{namespace:image.png}}
  * Resize to a width: {{namespace:image.png?600}}
  * Add a caption (tooltip): {{namespace:image.png|Scope screenshot}}

If a file type is not embeddable, it will be shown as a link instead.

===== Getting Access and Troubleshooting =====

  * **I cannot see New Log.** You are not logged in, your account is not approved yet, or you do not have write access to this logbook. Contact an admin to request write access.
  * **"Existing entries can only be changed by an administrator."** This is the intended behavior. Write a reply instead.
  * **My file was refused.** Only images and ROOT files are accepted.
